\section{STAKEHOLDER REQUIREMENTS}
\begin{enumerate}
	\item [3.1] The system must be able to read a LEGALLY OBTAINED video game ROM off of a microSD card.
	\item [3.2] The system must be able to play any video game that an origial GBA can run without additional hardware.
	\item [3.3] The system must be able to communicate with an exterior computer to send and receive Archipelago information.
	\item [3.4] The system must be in a easily handheld format that is not tiring to hold or play.
	\item [3.5] The system must have inputs as similar to the original GBA as possible.
	\item [3.6] The system must be battery powered and portable.
	\item [3.7] The system must be easy to set up and use.
\end{enumerate}
