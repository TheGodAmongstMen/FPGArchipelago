\section{SCOPE}


\begin{enumerate}[(a)]
	\item \textbf{\underline{General:}} \textbf{The scope of this document is to discuss and outline the requirements for FPGArchipelago, a system designed on an FPGA to emulate a Game Boy Advance with native Archipelago support. This documents provides stakeholder and engineering requirements for the FPGArchipelago system, as well as methods of verifications for the engineering requirements.}
